ComfyUI (default)

All steps run on your local ComfyUI with the bundled Qwen-Image workflows. With Docker Compose this is the comfyui service; for a ComfyUI already running on this computer use http://host.docker.internal:8188.

Fallback workflows for steps whose model is not a workflow

Cloud API keys (optional)

Only needed if you switch a step to fal.ai or Google. Stored only in the app's data folder. Leave blank to keep the current key. Environment variables FAL_KEY and GEMINI_API_KEY also work.

Provider and model for each step

Mix and match. For ComfyUI the model is a workflow (builtin:… or a path to your own API-format JSON). "mock" draws free placeholders to try the app. Prices are only used for the cost preview. Switching a step to fal.ai fills in recommended values; for fal also lower the detail tiles to 3 and scale to 2 to keep costs down.
